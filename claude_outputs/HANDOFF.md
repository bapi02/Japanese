## 목표
HIVE 마케팅의 "한화생명 시그니처 2027 연간 운영" 견적서(10개 프로젝트)를 바탕으로, 웨커(WACKER co., ltd.) 양식의 넘버스 견적서를 만든다.
사용자가 1번 "시그니처 위크"를 직접 넣어둔 서식을 그대로 따라 2~10번을 채우는 것에서 시작했고, 이후 HIVE와 너무 똑같지 않게 항목·금액을 바꾸는 방향으로 진행했다.

## 사용자가 정한 규칙 (반드시 유지)
1. **서식은 사용자가 고친 베이스 파일 그대로.** 검은 제목 행 오른쪽 빈 칸은 아래선만, Sub-List/Description 셀은 세로 가운데 정렬, 합계표 제목 행 오른쪽은 칠 없음, 상단에 "VAT Included" 행(=B6×1.1).
2. **소계(Sub Total)와 Cost Total 금액은 회계 서식(₩, 천 단위 구분)이어야 한다.** 넘버스는 "통화 셀" 타입에만 통화 서식을 적용하므로, 셀 타입까지 원본 소계 셀에서 복사해야 한다 (`build2.py`의 `apply_snap`). 이걸 놓쳐서 사용자가 여러 번 수동 수정했음.
3. **수식 필수.** 각 행 Amount `=F×G×H`, Sub Total `=SUM(...)`, Cost Total = 소계 셀 합, 합계표는 각 Cost Total 참조, AGENCY FEE `=SUM(H..)×0.1`, Project Total `=SUM(H..:I..)`, 상단 Total Quotation `=H<Grand Total>`. 넘버스 수식은 상대 참조 AST로 저장되며 `build2.py`가 직접 생성한다.
4. **VAT 포함 총액 약 20.5억.** 정확히 2,050,000,000은 1.21로 나누어떨어지지 않아 근사치로 합의. 금액은 10만 원 또는 1,000원 단위로 떨어지게 (2,038,876 같은 끝자리 금지). 끝자리 보정은 각 프로젝트 ETC의 "공과 잡비"(10만 원 단위 반올림)로.
5. **인건비·운송비·운영 인력 단가는 전 프로젝트 공통 단가표.** 행사 성격 차이는 수량·일수로만. (설치/철거 인건비 350,000, 야간 380,000, 렌탈 세팅 250,000, 5톤 탑차 800,000, 3.5톤/1톤 650,000, 오퍼레이터·엔지니어 500,000, 운영 디렉터 450,000, 슈퍼바이저 350,000, 진행요원 200,000, 사무국 TM 180,000, 의전 도우미 400,000, 포토그래퍼 1,500,000/일). `wacker_spec.py`의 `RATE`와 `normalize()`에 구현.
6. 항목 내용은 HIVE와 다르게 보이도록 문구·구성을 바꾸되 행사 실체(장소, 인원, 일정)는 유지.
7. 에이전시 피는 HIVE처럼 전체 Cost의 10% (옛 템플릿의 "인건비 제외" 문구는 삭제).

## 기술 메모
- `numbers-parser` 4.22 + `protobuf>=7.36.2`. 쓰기 시 주의점: `write()`는 스타일·테두리·수식을 버리므로 스냅샷 후 복원; 병합은 region map만 갱신되고 calc engine의 merge_owner 캐시는 수동으로 비움; `add_row/delete_row`는 병합·행 높이를 옮기지 않음.
- 사용자 맥의 "클로드" 폴더에 자동 저장을 원했으나 클라우드 세션이라 불가. Remote Control로 폴더를 연결하면 가능.
